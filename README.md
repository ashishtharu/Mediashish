# HealthHub — Health & Wellness Website

A mobile-friendly static health information website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — article search and category filtering

## Run on your phone
You can open `index.html` in a browser/local HTML editor, or upload all three files to GitHub and enable GitHub Pages.

## GitHub Pages
1. Create a GitHub account.
2. Create a new repository (for example `healthhub`).
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open the repository's **Settings → Pages**.
5. Select the main branch and root folder, then save.
6. GitHub will provide the live website address.
